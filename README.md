# SuperApp

Модульное десктопное приложение на Python с набором утилит.

## Утилиты

- **💰 Currency Tracker** — отслеживание динамики курсов валют ЦБ РФ
  с интерактивными графиками за произвольный исторический период.

> Следующие утилиты запланированы и представлены заглушками.

## Технологии

- Python 3.10+
- **PyQt5** — UI-фреймворк
- **pyqtgraph** — интерактивные графики
- **requests** — HTTP-клиент для API ЦБ РФ

### Обоснование выбора UI-фреймворка

Выбран **PyQt6** по следующим причинам:

1. **Встроенный `QStackedWidget`** — идеально подходит для модульной
   архитектуры SuperApp с переключением между утилитами без ручного
   управления видимостью.
2. **pyqtgraph** обеспечивает быстрые интерактивные графики
   (зум, панорамирование, экспорт) — критично для отображения
   динамики валют.
3. **Зрелая экосистема** — стандарт индустрии для десктопных
   приложений на Python, обширная документация и примеры.
4. **Нативные виджеты** — приложение выглядит нативно на Windows,
   Linux и macOS.

## Архитектура

Приложение построено на паттерне **Module Registry**:

- `core/` — ядро: контроллер главного окна, реестр модулей, конфиг, логгер.
- `modules/` — независимые утилиты, реализующие `BaseModule`.
- `utils/` — общие утилиты (заглушки).

Каждый модуль изолирован: своя UI, сервис и провайдер данных.
Добавление новой утилиты не требует изменений в ядре.
